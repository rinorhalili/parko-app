# Parking Data Sources

Parko combines community reports, OpenStreetMap-derived parking geometry, municipal parking metadata where available, and user-saved parking history.

The bundled Prishtina Parking snapshot is generated from the operator's
[official map](https://prishtinaparking.net/harta/). Visitor prices follow the
operator's published zone tariffs: 1 €/hour in Zone 1 and 0.50 €/hour in Zone
2, including the explicitly published barrier-parking exceptions.

Named private garages and public shopping-centre parking points are maintained
in a separate, manually reviewed Google Maps snapshot. The app links each point
back to its public listing. Private points use the product's 1 €/hour rule;
verified public shopping-centre parking is marked free.

Community availability is intentionally short-lived. Reports expire so stale parking availability does not remain visible as live data.
